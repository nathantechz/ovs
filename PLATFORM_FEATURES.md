## 🎯 Platform Overview

OLH is a **comprehensive, professional-grade optometry education platform** designed for students, faculty, and institutions worldwide. It combines world-class lecture materials, university curricula, textbook references, and advanced learning tools in one centralized hub.

### Key Statistics
- **📚 42 Courses** across Bachelor, Master, and Doctor programs
- **📖 123+ Textbooks** referenced across 22 subject categories
- **🎓 25+ Universities** listed globally
- **🌍 12+ Countries** represented
- **📝 600+ Study Materials** (lectures, notes, practicals)
- **✅ Professional Quality** - Designed for direct classroom teaching

## 📥 Feature 8: PDF Download System

**Purpose:** Allow students to download materials

**Features:**
- ✅ One-click downloads
- ✅ All PDFs watermarked with OLH branding
- ✅ GitHub repository link in footer
- ✅ Clickable hyperlinks for attribution
- ✅ Professional presentation quality

**Watermarking System:**
- Script available: `scripts/add-watermark.py`
- Adds OLH branding
- Includes GitHub repository link
- Maintains document quality
- Can batch process multiple files

**Usage:**
```bash
# Single file
python scripts/add-watermark.py input.pdf output.pdf

# All materials
python scripts/add-watermark.py --process-all materials/
```
